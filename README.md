XCutors is a curated collection of popular Roblox script executor tools bundled with a universal loader. It packages Volt, Synapse Z, Potassium, Wave, and xcutorsLoader into a single convenient download for Windows users.

Yes. XCutors and all included executors are distributed free of charge. Always download from the official GitHub Releases page to avoid tampered copies.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11, both 64-bit editions. Administrator privileges are required for script injection.

### Can I use my own custom Lua scripts?

Absolutely. You can load any Lua 5.1-compatible script via the file picker, drag-and-drop, or by pasting code directly into the script editor panel.

### How do I update to the latest version?

Check the GitHub Releases page periodically or watch the repository for update notifications. Download the newest archive and replace your existing files.

### Is it safe to download from this repository?

Only downloads from the official GitHub Releases page are verified. Avoid third-party mirrors or re-uploads, as they may contain modified or unsafe files.

### Which executor should I choose?

Each executor has different strengths. Volt is known for speed, Synapse Z for broad script compatibility, Potassium for stability, and Wave for its modern UI. xcutorsLoader lets you switch between them easily.

### Do I need to disable my anticomponent?

### Does this work on Roblox mobile or Mac?

No. XCutors is designed exclusively for Windows desktop. Roblox on mobile, macOS, Xbox, and other platforms is not supported.
